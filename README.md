# Frontline: Arena

Original browser-based FPS prototype inspired by tactical and mobile shooters. Uses Canvas raycasting, no external assets or packages.

## Play locally
Open `index.html` in a modern browser. Desktop: WASD, mouse, left click or Space, R reload, Q switch weapon, Shift sprint, right click aim. Mobile: joystick, drag camera, fire/reload/weapon/aim buttons. Landscape mode recommended.

## Publish on GitHub Pages
Repository Settings → Pages → Deploy from a branch → main → / (root) → Save. Wait for GitHub to publish the site.

## Features
Seven enemy bots, 15-elimination victory objective, two weapons, city map, minimap, health, 10-second respawn, pause and restart.

## Current limitations
Single-player offline prototype, procedural raycast graphics, no multiplayer server, no native APK. Browser/device testing is still needed.
